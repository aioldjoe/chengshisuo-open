01 / CORE
品牌核心

不是展示技術，
是把事情往前推。

成事所的視覺語言要像一個可靠的工作夥伴：先把重點講清楚，再把下一步交到你手上。

「工具不搶戲，結果要到位。」

01

清楚

第一眼知道這是什麼、現在在哪、接下來能做什麼。

02

務實

少一點概念展示，多一點可以直接拿去用的結果。

03

可靠

同一個品牌在網站、產品與訊息裡都保持同樣的性格。

04

人味

技術藏在後面，前面留下的是好理解、好接近的語氣。

02 / LOGO
標誌系統

讓「成事」
直接成為記號。

不加旗子、箭頭或抽象符號。品牌名稱本身就是最短、最有記憶點的圖形。

A / 成事章

主品牌章。適合網站入口、產品封面、品牌物料與第一次介紹品牌的場景。

B / 成章

小尺寸 Icon。適合 favicon、App icon、LINE 頭像與瀏覽器頁籤。

03 / COLOR
色彩系統

暖紙白留空間，
磚紅留下記憶點。

色彩有溫度，但不喧鬧；有辨識度，但不壓過內容。所有畫面先讓人讀懂，再讓人記住。

成事磚紅

#B65A4A

主 Logo、主要 CTA、關鍵狀態與少量識別標記。低飽和使它適合長期使用，也能和暖紙白形成穩定對比。

暖紙白

#F8F6F4

墨灰

#383432

點擊任一色票可複製 HEX。乾燥玫瑰只作柔和輔色，不與磚紅同時搶主位。

70% / PAPER
20% / INK
10% / BRICK

建議比例：大面積留給暖紙白，墨灰負責閱讀，磚紅只在需要被看見的地方出現。

04 / TYPE
字體與排版

字體不表演，
讓事情抵達。

成事所需要的是可讀性，不是重量感。標題有份量但不黑粗，內文有呼吸、按鈕有方向。

05 / GRAPHIC
圖形與介面語言

把「正在整理」
變成介面細節。

圓角容器、清楚標籤、單一路徑的主要動作，都是讓使用者少想一點、快做一點的工具。

間距基礎 / 4px grid

以 4px 為基礎，常用間距收斂在 8、16、24、32px。規則越少，整體越像一個系統。

圓角層級 / radius scale

08162432

小元件 8px、卡片 16px、區塊 24px、主視覺 32px。圓角是秩序，不是裝飾。

07 / RULES
使用規範

少一點裝飾，
多一點判斷。

一致性不是每一頁長得一樣，而是每一次變化都仍然能被辨認為成事所。

✓應該這樣做

保持水平、置中、留白完整；在不同尺寸用對應的字數。

×不要這樣做

不旋轉、不加投影、不拉伸、不任意換色，也不使用過重字體。

看得懂第一次接觸的人，能在 3 秒內知道品牌與動作。
找得到主要按鈕、狀態與下一步，有清楚的層級與對比。
做得到視覺不只是好看，而是把人推到下一個可執行結果。
